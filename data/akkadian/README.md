## ساختار `akkadian_dictionary.json`

```json
{
  "meta": {
    "title": "Akkadian–English dictionary (consolidated from Oracc glossaries)",
    "license": "CC BY-SA 3.0",
    "attribution": "© respective Oracc projects, reused under CC BY-SA 3.0",
    "projects": ["rinap/rinap1", "saao/saa01", "dcclt", "cams/gkab", "ogsl", ...],
    "entry_count": 11154,
    "fields": { ... }
  },
  "entries": [
    {
      "translit":  "šarru",        // آوانگاری لاتین (سرواژه)
      "pos":       "N",            // نوع کلمه: N اسم، V فعل، AJ صفت، AV قید، PRP حرف‌اضافه، NU عدد، ...
      "en":        ["king"],       // معانی انگلیسی (guide word + senses)
      "logograms": ["LUGAL","MAN"],// نوشتار لوگوگرامی (سومروگرام)
      "cuneiform": "𒈗",           // خط میخیِ یونیکدِ لوگوگرام (اگر موجود باشد)
      "freq":      21601,          // بسامدِ کاربرد (تعداد نمونه‌های واقعی)
      "sources":   ["rinap",...],  // پروژه‌های Oracc که این واژه از آن‌ها آمده
      "id":        "šarru[king]N"  // شناسه‌ی Oracc
    }
  ]
}
```

- مدخل‌ها **بر اساس بسامد** مرتب‌اند (پرکاربردترین‌ها اول) — برای مترجم عالی است.
- **جستجوی دوطرفه** مثل اپ: هم روی `translit` و هم روی آرایه‌ی `en`.
- **۶۳۵ مدخل** خط میخیِ یونیکد دارند؛ بقیه چون هجایی نوشته می‌شوند لوگوگرام/خط‌میخیِ تک‌نشانه ندارند (طبیعی است).
- ویرایش‌پذیر: `entries` یک آرایه است؛ کم/زیاد کردن راحت است.

## این دیتا از کجا آمد و چطور کامل شد

1. **منبع اصلی:** گلاسری‌های **Oracc** (Open Richly Annotated Cuneiform Corpus) از ۲۳ پروژه‌ی
   پرمحتوای اکدی — کتیبه‌های سلطنتیِ نو-آشوری/بابلی (rinap, riao, ribo)، نامه‌ها و آرشیوهای
   دولتی (saao/saa01…saa19)، متون ادبی/جادویی/پزشکی (cams, cmawro, blms, akklove, asbp/ninmed)،
   فنی (glass, oimea, suhu) و **فهرست‌های واژگانیِ باستانی (dcclt)** که غنی‌ترین منبع واژه‌اند.
   مجوز: **CC BY-SA 3.0**.
2. **خط میخی:** با **OGSL** (Oracc Global Sign List) نامِ لوگوگرام‌ها به کاراکترِ یونیکدِ خط‌میخی
   نگاشت شد (LUGAL→𒈗). مجوز: CC BY-SA.
3. **پیکره‌ی نمونه:** `akkadian_english_corpus.txt` (MIT) برای جمله‌های ترجمه‌شده.
4. روشِ گرفتنِ دادهٔ Oracc (برای افزودنِ پروژه‌های بیشتر در آینده):
   `http://oracc.museum.upenn.edu/json/<project>.zip` (زیرپروژه: `parent-sub.zip`)، سپس
   فایل‌های `gloss-akk*.json` داخل zip.

## قدم بعدی (بعد از تأیید)
ساختِ خودِ بخش **Translate** در `index.html`: جعبه‌ی جستجوی دوطرفه که این JSON را می‌خواند،
نتیجه را با `translit / معنی / نوع کلمه / لوگوگرام / خط میخی` نشان می‌دهد، و با همان افکت **fade**
باز می‌شود. (اختیاری: افزودنِ یک لایه‌ی «هسته/عبارت‌های پرکاربرد» دست‌چین.)
